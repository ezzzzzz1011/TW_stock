# TW.stock.app — 台股與 ETF 投資管家

從行情追蹤到現金流規劃，為存股族打造的個人化投資儀表板。

以 Python + Streamlit 開發，提供台股與 ETF 即時報價、歷史本益比估值、配息預估、資產配置分析與股利報稅試算。投資組合與關注清單透過 Google Sheets 雲端同步，換裝置也不會遺失。

線上系統：https://ez-stock-fhedmdgxgniyeyhfxexy3m.streamlit.app/

## 功能

### 個股分析

輸入股票代碼即可，系統自動完成以下運算：

- **近四季 EPS 自動抓取**。不是把四季 EPS 直接相加——公司配股或增資後，財報會追溯調整舊季度的 EPS，直接相加會高估。系統改用「四季稅後淨利加總 ÷ 同一加權平均股數」還原，並在畫面上列出四季明細供核對。
- **歷史本益比河流圖**。取該股自己近 3／5／10 年每個交易日的本益比分布，以 10／30／70／90 百分位為分界切出極便宜、便宜、合理、昂貴、極昂貴五段價位，50 百分位為合理價。判讀、位階表格與標亮列使用同一份定義。用固定倍數套所有股票沒有意義，台積電長年在 20～30 倍，傳產可能只有 10 倍。上市未滿所選年數時，畫面會標示實際涵蓋的期間。
- **適用性警示**。最新近四季 EPS 為虧損時直接說明無法估價，不顯示負的價位；取樣期間內曾虧損，或近兩年 EPS 變異係數過大時，會提醒此為景氣循環股或獲利不穩，本益比法不適用。
- **資料日期**依報價實際所屬的交易日顯示，假日查詢會標示「最近一個交易日」。
- 另提供自訂本益比的手動試算，供假設情境使用。

### ETF 分析

- **配息頻率自動偵測**：分析歷史除息間隔，判斷月配、季配、半年配或年配，並可手動修正。
- **停發偵測**：距上次配息超過預期間隔加寬限期時，自動在期數中補零，避免高估年配息。
- **現金股利含公積配息**：盈餘配息與資本公積配息合併計算（例：台灣大、遠傳每年都有公積配息）。
- **年配息推估方式**：年配取最新一次、半年配取最近 2 次、季配取最近 4 次加總，月配以最近 4 次平均 × 12 推估，畫面上會註明，反映最近的配息水準。
- **殖利率估值**：依 10%／7% 殖利率推算便宜價與合理價區間。
- **二代健保試算**：單次給付達 20,000 元時，依 2.11% 費率計算補充保費，呈現實領金額。
- **存股複利試算**：設定初始資金、每月投入與領出、年化殖利率與年數，推算期末資產與每月被動收入。

### ETF 殖利率排行

- 自動抓取**全部上市、上櫃 ETF**（約 200 多檔）近一年的現金配息，依殖利率由高到低排名。
- 可選擇顯示**前 20 名、前 50 名或全部**；可依「近 12 個月殖利率」或「年化殖利率（依最新配息推估）」排序；可篩選股票型、債券型、平衡型等類型。
- 備註欄標示需要留意的情況：上市未滿一年、可能停發、除息日提前導致一年內算到兩次。
- 選一檔即可直接跳到「ETF 分析」查看詳細試算。
- 資料來源為證交所與櫃買中心的除權除息計算結果表與每日收盤行情，不需 FinMind 付費會員。

### 投資組合

- 帳號登入，投資清單與關注清單存於 Google Sheets，重啟不遺失。
- 自動帶入股票名稱與戰略屬性（進攻型／現金流／防守型）。
- 市值、報酬率、預估年領股息、組合平均殖利率一次呈現。同一檔分多列輸入（例如分批買進）時，張數自動加總。
- 個股配置與戰略佔比雙圓餅圖。
- **領息排程月曆**：依配息頻率往未來推估下一次除息日，發放日再加 28 天，標示「已公告」或「推估」。與市值計算一樣使用畫面上正在編輯的表格，尚未儲存的修改也會反映。

### 大盤指數

- **台股**：加權指數、當日成交金額（含與前一交易日比較）。
- **美股**：S&P 500、道瓊、納斯達克、費城半導體、VIX 恐慌指數，標示為前一交易日收盤。
- **匯率與原物料**：美元／台幣、美 10 年債殖利率、原油期貨、黃金。
- **三大法人買賣超**：外資、投信、自營商與合計，資料取自證交所。外資自營商依證交所定義不重複計入。
- **加權指數走勢圖**：可切換近一月至近五年，附區間漲跌與盤中高低。

### 股利報稅試算

- 支援 **114 / 115 年度**切換，稅制參數集中管理，每年只需更新一組設定。
- 薪資特別扣除額按人分別計算，取實領薪資與上限之低者。
- 免稅額：年滿 70 歲的本人、配偶與受扶養直系尊親屬適用 1.5 倍，其他人適用一般免稅額。
- 儲蓄投資特別扣除額依填入的利息所得自動計算（上限 27 萬），利息同時計入綜合所得。
- 教育學費特別扣除額依每位子女實際繳納的學費計算，每人上限 2.5 萬。
- 標準扣除額與列舉扣除額自動比較，採用較高者。
- **排富條款自動判定**：課稅級距達 20%、選擇股利 28% 分開計稅、或基本所得額超過 750 萬時，長期照顧與房屋租金特別扣除額自動歸零。幼兒學前特別扣除額自 113 年度起已刪除排富規定，不受影響。
- 並列「合併計稅」與「股利 28% 分開計稅」兩方案的完整明細與結算單，並指出何者較有利。

## 技術架構

| 模組 | 技術 / 服務 |
| :--- | :--- |
| 介面 | Streamlit |
| 資料庫 | Google Sheets（gspread） |
| 即時報價 | Fugle API |
| 財報與配息 | FinMind |
| 歷史股價與國際指數 | yfinance |
| 法人、成交金額、本益比 | 證交所 OpenAPI、櫃買中心 OpenAPI |
| 配息備援 | Yahoo Finance、HiStock |
| 資料處理與圖表 | pandas、Plotly Express |

配息採三層備援：依序嘗試 FinMind、Yahoo、HiStock，取第一個成功的來源。EPS 在 FinMind 失效時改以交易所公告的本益比反推：上市股票用證交所、上櫃股票用櫃買中心。

## 檔案結構

```
testapp.py    進入點：版面設定、session 狀態、登入判斷、路由
common.py     主題顏色、稅制參數、通用工具
data_api.py   資料引擎：Google Sheets、報價、配息、財報、大盤
pages.py      登入頁、側邊欄與所有功能頁（每頁一個 page_xxx 函式）
tests/        端對端測試（見下方「開發與測試」）
```

金鑰一律從 Streamlit Secrets 讀取，程式碼中不含任何憑證。所需設定：

```toml
[finmind]
token = "..."

[fugle]
token = "..."

[admin]                      # 選填：可使用「清除全站資料快取」的帳號
users = ["你的帳號"]

[gcp_service_account]
# Google 服務帳號 JSON 內容，此區塊須放在最後
```

TOML 的區塊會延伸到下一個標頭為止，因此小區塊必須寫在 `[gcp_service_account]` 之前。

### 帳號安全

- 密碼以 PBKDF2-SHA256 雜湊後存放，試算表中不含明碼。舊帳號的明碼密碼會在該帳號下次登入成功時自動轉為雜湊。
- 同一帳號連續登入失敗 5 次，鎖定 5 分鐘。
- 「清除全站資料快取」只開放給 `[admin] users` 名單中的帳號；側邊欄「資料來源診斷」會顯示目前帳號有沒有管理員權限，以及沒有權限的原因。修改名單後重新整理即可生效，不需重啟。

## 開發與測試

```bash
pip install -r requirements.txt
python tests/run_tests.py
```

測試以 Streamlit AppTest 實際執行整個網站（登入、各頁面、估價、配息、報稅、大盤等），全部通過時結束代碼為 0。Google Sheets 與 Fugle 以 `tests/fakes.py` 的替身代替，不會碰到正式資料；FinMind、yfinance、證交所、櫃買中心會實際連線，因此需要網路。

`requirements.txt` 各套件設有「已測試版本的下一個主版本」上限，避免套件大改版時網站在重新部署時突然壞掉。要放寬上限時，先在新版本下跑過測試。

每年 11 月底財政部公告新年度的基本生活費後，更新 `common.py` 的 `TAX_CONFIG` 對應年度的 `basic_living`，並把 `basic_living_confirmed` 改為 `True`。
